WHAT YOU ARE BUILDING
─────────────────────
A complete, production-ready frontend redesign for a real-time
road safety monitoring platform running on Indian city roads.
The backend is FastAPI + WebSocket — DO NOT change any API calls,
WebSocket logic, or data processing. Only the visual design,
layout, and CSS change. Every feature must work identically.

Design language: Modern civic-tech dashboard. Clean, professional,
trustworthy. Think Google Maps + government control room + Notion.
Light/dark toggle. Primary color: deep saffron-orange (#F97316).
Accent: India-green (#16A34A). Danger: red (#DC2626).
Background: near-white (#FAFAFA) in light mode, slate (#0F172A)
in dark. Fonts: Inter (headings) + DM Sans (body). Rounded cards,
subtle shadows, generous whitespace. No neon, no cyber aesthetic.

════════════════════════════════════════════════════════════════
EXACT API CONTRACT — DO NOT CHANGE
════════════════════════════════════════════════════════════════

WebSocket:
  ws://{location.host}/ws
  Message format: { type: "state", buses: [...], events: [...], alerts: [...] }
  Bus object: { id, route, lat, lng, speed, network, icon }
  Event object: { id, type, icon, lat, lng, confidence, severity, detected_by,
                  ts, age_s, verification, verifier_count, emergency, timeline }
  Alert object: { ts, type, level, msg, event_id }

REST endpoints (all relative paths, same host port 8000):
  GET  /api/routes              → { routes: [{id, name, color, waypoints:[{lat,lng}]}] }
  GET  /api/health              → { status, uptime_s, buses, events, ws_clients, ai_available }
  GET  /api/events/all          → { events:[...], total, status_counts, sev_counts }
  GET  /api/events/{id}         → full event with assignments, priority, full_timeline
  POST /api/events/{id}/priority/{level}  body: none  (level: p1|p2|p3|p4|none)
  POST /api/events/{id}/assign/{auth}     body: none
  DEL  /api/events/{id}/assign/{auth}     body: none
  GET  /api/authority/{auth}/events       → { authority, items:[...], counts, total }
  POST /api/authority/{auth}/work/{id}/{action}  body: {}  (action: acknowledge|start|complete)
  POST /api/authority/{auth}/work/{id}/note      body: { notes: "string" }
  POST /api/detect/image         body: FormData file  → { detections, traffic, summary }
  POST /api/detect/image/annotated body: FormData file → JPEG binary
